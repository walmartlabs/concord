# Using Ansible with Windows Hosts

This example uses the `groupVars` parameter to export a secret as an Ansible [group_vars](https://concord.walmartlabs.com/docs/plugins/ansible.html#group-vars) file.
Use group variables to apply variables to multiple hosts.

For information about Windows server authorization with Concord, see [Windows](https://concord.walmartlabs.com/docs/plugins/ansible.html#windows).
