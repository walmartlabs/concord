# Forms

This example shows how to use forms in processes.

## Running

1. Start the process.
   ```
   cd examples/forms
   ./run.sh localhost:8001
   ```

2. Open [the console](http://localhost:8001).
3. Open the process page.
4. Start the wizard.
5. Fill out the form. Click "Submit".
6. Check the process logs for a "Hello, John Smith" message.
